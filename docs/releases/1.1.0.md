# 福大签到助手 1.1.0

- 新增可选每日自动签到：默认关闭，自行设定北京时间并保存，之后无需打开 App，可随时修改。
- 新增结果通知、最近执行结果、暂停恢复和系统设置入口；拒绝通知不影响执行。
- 手动和自动签到共用入口，提交记录持久保存。响应超时、进程重启后只查询确认，不自动重复提交。
- 每次核对学校最新计划、服务器时间和签到方式。校外方式需手动填写地址；验证码或认证失败暂停自动功能。
- 沿用原包名和发布签名，支持覆盖升级并保留账号；升级后自动功能保持关闭。

后台执行可能因系统省电、后台限制或网络延迟，不能保证准时或在截止前完成。强制停止后需重新打开 App。学校查询确认成功才算签到成功，真实后台执行需在自己的设备上主动开启后验证。

此文件是待发布说明，不代表 GitHub Release 已创建。安装包和校验文件应作为 Release 附件上传，不进入源码历史。验证范围见 `docs/verification.md`。
